# StudyMate

교내 스터디 매칭 및 관리 플랫폼

> 아주대학교 2026-1 소프트웨어공학 팀 프로젝트

---

## 프로젝트 소개

대학생들은 스터디 모집은 에브리타임, 소통은 카카오톡, 자료 공유는 노션·구글 드라이브로 각각 따로 관리하고 있습니다.  
**StudyMate**는 스터디 탐색 → 모집 → 팀 구성 → 운영 관리까지의 전체 라이프사이클을 하나의 플랫폼으로 통합합니다.

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| 회원가입 및 프로필 설정 | 학교 이메일 인증, 관심 분야 및 사용 언어 등록 |
| 스터디 모집 게시판 | 태그 기반 검색·필터로 스터디 탐색 및 모집 글 등록 |
| 지원 및 수락 시스템 | 지원 → 스터디장 수락/거절 → 팀 공간 자동 접근 |
| 팀 전용 게시판 | 팀원 전용 공지·자유게시판 및 댓글 |
| 출석 체크 | 회차별 출석 기록 및 참여 현황 조회 |
| 스터디 자동 추천 | 프로필 관심 태그 기반 맞춤형 스터디 추천 |
